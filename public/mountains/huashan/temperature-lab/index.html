05 · 导入真实测温记录

每行3列：测点名, 海拔米, 2米气温℃。同批测点应尽量同时间测量，并记录设备、地理坐标与天气。至少4个测点、3个不同海拔。

尚无实测数据，不能声称模型精度。

研究说明

这是科研原型，不是已经完成的山地测温科研成果。温度估算依赖简化模型；地表温度与2米空气温度不可直接混用。要形成挑战杯创新点，应收集真实山地测温记录，再与固定温度梯度、实测拟合及考虑坡向/日照的多变量方法进行对照测试。
数据：Open-Meteo API / NASA MODIS（由原有模块提供）/ 项目内五峰参考海拔。该原型不用于登山安全决策。
